## 面试演示顺序

1. 展示架构：为什么任务记录本身就是队列，为什么 HTTP 不在数据库事务里。
2. 跑 `make demo-production PYTHON=.venv/bin/python`：成功、503 重试、结果不明待核对。
3. 打开生成报告，区分供应商调用次数、业务副作用次数和本地状态。
4. 解释一个反例：供应商已成功但响应丢失时，租约不能撤销它，不能直接重复发送。
5. 说明复杂度取舍：不再扩展通用通知平台，生产 HA/负载/真实契约留给明确需求后的验收。
